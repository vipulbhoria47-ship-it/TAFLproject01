# TAFLproject01
🚀 NFA to DFA Converter & Generator

🌐 Live Demo: [vipultaflproject2.netlify.app](https://vipultaflproject2.netlify.app/)

An interactive web-based tool to design, analyze, and convert Non-Deterministic Finite Automata (NFA) into Deterministic Finite Automata (DFA).

This project goes a step further by allowing users to input a problem statement, automatically generate the corresponding NFA, and then convert it into a DFA with complete transition tables.

✨ Features
🔁 NFA to DFA Conversion
Converts any given NFA into an equivalent DFA using subset construction.
🧠 Automatic NFA Generation
Provide a problem statement → tool generates:
States
Alphabet
Transition function
Start & Final states
📊 Transition Table Visualization
Displays:
NFA transition table
DFA transition table
🎯 User-Friendly Interface
No need to manually define all transitions
Ideal for beginners learning Theory of Computation
⚡ Instant Results
Real-time conversion and visualization
📌 Problem It Solves

Most tools require users to manually input full transition tables.
This project simplifies the process by:

👉 Understanding the problem statement
👉 Generating the complete NFA automatically
👉 Converting it into a DFA without extra effort

This makes learning automata easier and faster.

📖 How It Works
Enter a problem statement (e.g., strings ending with "01")
Tool analyzes and constructs the NFA
Displays:
States
Transition functions
Converts NFA → DFA using subset construction
Shows final DFA transition table

NFA to DFA conversion is a core concept in automata theory and widely used in compilers and pattern matching systems
